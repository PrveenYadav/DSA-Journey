# DSA-Journey: My Journey from Basics to Advanced

This repository documents my journey through Data Structures and Algorithms (DSA). I embarked on this challenge to solidify my understanding of core computer science concepts and improve my problem-solving skills. This README provides an overview of my experience, the topics I covered, and the resources I used.

## About the Journey

This was a self-driven learning initiative where I committed to spending a consistent amount of time each day learning and practicing DSA. I aimed to cover a wide range of topics, starting with the fundamentals and gradually progressing to more complex algorithms and data structures.

**Key Goals:**

* **Solidify foundational DSA knowledge:** Gain a deep understanding of essential data structures and algorithms.
* **Improve problem-solving skills:** Develop the ability to analyze problems, design efficient solutions, and implement them in code.
* **Enhance coding proficiency:** Become more comfortable with coding in C++.
* **Build a strong portfolio:** Create a collection of solved problems and implemented data structures.
* **Consistency:** Form a daily habit of learning and coding.

## Topics Covered

I followed a structured approach, covering the following topics in a logical progression:

**1. Fundamentals:**
 * **Basics:**
    * Flowcharts and Pseudo Code
    * Patterns/Playing with Loops
    * Vectors

* **Introduction to DSA:** What is DSA, its importance, and basic concepts.
* **Time and Space Complexity:** Understanding Big O notation and analyzing algorithm efficiency.
* **Basic Data Structures:**
    * Arrays
    * C++ STL
    * Linked Lists (Singly, Doubly, Circular)
    * Stacks
    * Queues
    * OOPs in C++

**2. Intermediate Data Structures and Algorithms:**

* **Trees:**
    * Binary Trees
    * Binary Search Trees (BST)
    * Tree Traversals (Inorder, Preorder, Postorder)
    * Balanced Trees
* **Heaps:**
    * Binary Heaps
    * Priority Queues
* **Hashing:**
    * Hash Tables
    * Hash Functions
* **Sorting Algorithms:**
    * Bubble Sort
    * Insertion Sort
    * Selection Sort
    * Merge Sort
    * Quick Sort
    * Heap Sort
* **Searching Algorithms:**
    * Linear Search
    * Binary Search

**3. Advanced Algorithms and Problem Solving:**

* **Graphs:**
    * Graph Representations (Adjacency Matrix, Adjacency List)
    * Graph Traversals (BFS, DFS)
    * Shortest Path Algorithms (Dijkstra, Bellman-Ford)
    * Minimum Spanning Trees (Prim, Kruskal)
* **Dynamic Programming:**
    * Memoization
    * Tabulation
    * Common DP Problems (Knapsack, Longest Common Subsequence)
* **Greedy Algorithms:**
    * Activity Selection Problem
    * Fractional Knapsack problem.
* **Backtracking:**
    * N-Queens Problem
    * Sudoku Solver.
* **Tries:**
    * Prefix Search
* **String Algorithms:**
    * String matching
    * KMP Algorithm
